RETAIL STORE PERFORMANCE ANALYSIS USING POWER BI

Included files:
- Retail_Store_Sales.csv: 1,200 synthetic transaction rows.
- Project_Report.docx: editable academic report.
- Project_Presentation.pptx: editable presentation.
- DAX_Measures.txt: measures to paste into Power BI.
- PowerBI_Setup_Guide.txt: step-by-step dashboard instructions.
- Dashboard_Preview.png: static preview based on the sample data.

IMPORTANT:
A native Power BI .pbix file is not included. Create it in Power BI Desktop by importing the CSV and following PowerBI_Setup_Guide.txt. The dataset is synthetic, not real store data.
